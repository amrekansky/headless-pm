# Product-Led Growth (PLG)

## What it is
Product-Led Growth is a go-to-market strategy where the product itself is the primary driver of acquisition, activation, conversion, and expansion — replacing (or supplementing) traditional sales-led or marketing-led funnels. Users experience core product value before they pay, and that experience is the sales pitch. Key examples: Slack, Figma, Notion, Dropbox, Calendly, Linear.

## When to use
- When product value is immediately demonstrable without a sales conversation
- When target users are self-serve capable (can discover and activate on their own)
- When the product has natural viral mechanics (collaboration, sharing, invitations)
- When CAC reduction is a strategic priority (PLG typically has 2–5x lower CAC than SLG)
- When the buying unit is the individual user who then expands to the team/org

**Not ideal when:**
- Product requires complex integration or onboarding before value is clear
- Sales cycle is inherently relationship-driven (regulated industries, government)
- The product's core value requires a large team to be in place before any single user benefits

## Core components

### 1. The PLG Flywheel
```
Acquisition → Activation → Retention → Expansion → Advocacy → (back to Acquisition)
```
Unlike a funnel (linear, losing users at each stage), the flywheel compounds: happy retained users become acquirers and advocates, feeding growth without proportional marketing spend.

**Each stage:**
- **Acquisition:** User discovers product via peer referral, search, or organic content — not outbound sales
- **Activation:** User reaches the "aha moment" — the moment they experience core product value
- **Retention:** User builds habits around the product; switches cost rises
- **Expansion:** User invites teammates, upgrades for more features, or expands seats
- **Advocacy:** User recommends product; viral loop begins again

### 2. Freemium vs. Free Trial
| Model | How it Works | Typical Conversion | Best For |
|---|---|---|---|
| **Freemium** | Free tier with limited features, forever | 2–4% free → paid | Products with strong viral loops, collaboration features |
| **Free Trial** | Full product free for fixed period (14/30 days) | 9–15% trial → paid | Complex products where users need full access to get value |

**Key insight:** Freemium gets more signups; free trials convert better. Choose based on how quickly users can experience core value — if value requires team collaboration, freemium's viral spread outweighs lower conversion.

### 3. Activation and the Aha Moment
**Activation** = the event where a user first experiences the product's core value.

**Time to Value (TTV):** How long between signup and activation event.
- Target: < 5 minutes for consumer products, < 24 hours for B2B
- Every friction point in onboarding that delays TTV reduces activation rate

**Identifying your aha moment:**
- Cohort analysis: which early actions predict retention 30/60/90 days out?
- Common pattern: "Users who do X within first 48 hours retain at 3x the rate"
- This action IS your activation event / aha moment

**Examples:**
- Slack: Send 2,000 messages as a team
- Dropbox: Upload first file and access it from a second device
- Twitter: Follow 30 accounts within first session
- Spotify: Create a playlist within first week

### 4. PQL (Product Qualified Lead)
A user who has demonstrated intent to upgrade through product behavior — not through form fills or demo requests.

**PQL scoring model:**
```
PQL Score = Engagement Score + Fit Score + Intent Signal
```
- **Engagement:** Actions taken (# sessions, features used, files created, invitations sent)
- **Fit:** Does the company/user match ICP? (company size, industry, role)
- **Intent:** Upgrade page visited, billing page viewed, seat limit hit

**PQL benchmarks:**
- PQL → paid conversion: 25–30% (vs. MQL → paid: 5–10%)
- The 3x conversion advantage is because PQLs have already proven value before a sales conversation

**When to route PQLs to sales:** When deal size justifies human touch (typically enterprise accounts). Self-serve for SMB/individual; sales assist for accounts above a seat/revenue threshold.

### 5. Viral Coefficient
**Formula:** `Viral Coefficient (k) = Average invitations sent per user × Invitation acceptance rate`

| k value | Growth pattern |
|---|---|
| k < 1 | Growth requires external inputs (paid acquisition, content) |
| k = 1 | Stable user base without external input |
| k > 1 | Exponential growth; each cohort is larger than the last |

**Example:**
```
Each active user invites 3 colleagues × 40% accept = k = 1.2
→ Exponential organic growth
```

**Improving viral coefficient:**
- Reduce friction in invitation flow
- Make the product demonstrably better with more users (collaboration, shared templates)
- Design features where the output is naturally shareable (Loom videos, Figma links, Canva designs)

### 6. Expansion Revenue and NRR
**Net Revenue Retention (NRR):** Revenue from existing customers at end of period ÷ revenue from same customers at start.

```
NRR = (Starting MRR + Expansion MRR - Churned MRR - Contraction MRR) / Starting MRR × 100
```

- NRR > 100% = company grows revenue from existing base even with some churn
- PLG benchmark: top quartile companies reach NRR > 120–130%
- NRR > 100% means the sales team is optional for base growth — expansion happens through product

**Expansion motions:**
- **Seat expansion:** Free users become paid as team adopts
- **Usage-based:** More API calls, storage, or records triggers upgrade
- **Feature unlock:** Power users hit free tier limits and upgrade

## Key questions to ask
- What is the specific user action that predicts 90-day retention? (Define your activation event)
- How long does it take a new user to reach that activation event? (Time to Value)
- What behavior pattern makes a user a PQL? (Define PQL threshold)
- What is preventing users from inviting teammates? (Viral coefficient lever)
- Is NRR > 100%? If not, is the issue churn or insufficient expansion?

## Common mistakes
- **"Just add a free tier" PLG:** PLG is an organizational strategy, not a pricing decision — requires product, onboarding, and CS to align
- **Ignoring activation:** Optimizing acquisition while activation is broken fills a leaky bucket
- **Vanity free user counts:** 1M free users at 0.5% conversion < 10K free users at 10% conversion
- **No PQL definition:** Sales teams waste time on free users who will never pay; define the threshold
- **Copying competitor PLG models:** Freemium that works for Notion doesn't work for enterprise infrastructure — match model to product complexity and viral mechanics

## Quick reference

**PLG health dashboard:**
```
Acquisition: Signup rate, source attribution, viral coefficient (k)
Activation: Activation rate, time-to-value, aha moment event completion %
Retention: D7/D30/D90 retention curves, session frequency
Expansion: PQL → paid conversion, seat expansion rate, NRR
Monetization: Free → paid conversion %, ARPU, LTV:CAC ratio
```

**PLG readiness checklist:**
- [ ] Activation event identified and measured
- [ ] Time-to-value < 5 min (consumer) or < 24h (B2B)
- [ ] Onboarding flow removes all friction before aha moment
- [ ] PQL definition documented and in CRM
- [ ] Viral/sharing mechanic built into core workflow
- [ ] NRR measured monthly
- [ ] Free tier limits tuned to trigger expansion, not abandonment
